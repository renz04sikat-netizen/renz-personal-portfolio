1. PURPOSE OF EACH FILE
--------------------------------------------------------------------------------
- index.html
  The main HTML5 webpage containing the complete semantic structure of the
  personal portfolio (Home, About Me, Skills, Certificates and Achievements,
  Hobbies and Interests, and Contact), linked to style.css, and
  including interactive JavaScript features (mobile menu toggle, active section
  highlighting, typing animation, scroll reveal, certificate modal preview,
  and copy-to-clipboard email button).

- style.css
  The external CSS3 stylesheet implementing the Modern Dark Mode ("Developer
  Terminal") theme (#0F172A background, #1E293B surface cards, #38BDF8 primary
  cyan, #10B981 emerald accent, and #F8FAFC text), responsive CSS Grid and
  Flexbox layouts, typography (Inter & JetBrains Mono), hover animations, and
  accessibility support.

- index_html_code.txt
  A plain-text backup copy of the complete HTML source code that matches
  index.html character-for-character for easy viewing, grading, or submission.

- README.txt
  This documentation file explaining the project files, how to view the
  portfolio locally, and how to publish it online using GitHub Pages.


2. HOW TO OPEN AND RUN THE PORTFOLIO LOCALLY
--------------------------------------------------------------------------------
Step 1: Extract all files from the ZIP archive into a single folder on your
        computer (keep index.html and style.css in the same folder).
Step 2: Locate the file named "index.html".
Step 3: Double-click "index.html" (or right-click -> "Open with" -> select your
        preferred web browser such as Google Chrome, Microsoft Edge, Firefox,
        or Safari).
Step 4: The portfolio website will load immediately in your browser.


3. HOW TO PUBLISH THROUGH GITHUB PAGES
--------------------------------------------------------------------------------
Step 1: Create a free GitHub account at https://github.com (or sign in to your
        existing account).
Step 2: Click the "+" icon in the top-right corner and select "New repository".
Step 3: Name the repository (for example: "renz-portfolio" or
        "<your-username>.github.io"), set visibility to "Public", and click
        "Create repository".
Step 4: On the repository page, click "uploading an existing file" (or "Add
        file" -> "Upload files").
Step 5: Drag and drop "index.html" and "style.css" into the upload area, then
        click "Commit changes".
Step 6: Go to the repository's "Settings" tab -> select "Pages" from the left
        sidebar.
Step 7: Under "Build and deployment" -> "Source", select "Deploy from a branch".
        Choose the "main" branch and "/ (root)" folder, then click "Save".
Step 8: Wait 1–2 minutes and refresh the Pages settings screen. GitHub will
        display your live portfolio URL (e.g.,
        https://<your-username>.github.io/renz-portfolio/).
